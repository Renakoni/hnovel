# 书源基础设置与账户状态（#215）

基础设置使用宿主已有的来源身份。打开页面不调用 `registry.resolve`，不执行书源脚本，也不发起登录或站点探测；禁用、尚未授权或加载失败的书源仍可进入设置。

## 固定分区与支持范围

| 来源 | 基础管理与配置 | 网络 | 账户 |
| --- | --- | --- | --- |
| 导入规则源 | 启用、作者说明；高级项含手动变量、授权、诊断与版本操作 | 使用 #214 的按源偏好；原生浏览器明确显示限制 | 按静态声明提供入口，读取当前账号的已保存状态 |
| Z-Library | 保留启用、镜像、授权和搜索操作 | 使用宿主 broker 的按源偏好 | 沿用既有能力，不增加通用登录表单 |
| Wenku8 等内置来源 | 来源信息及已有搜索入口 | Wenku8 显示尚未接入的具体提示（#220） | 不猜测来源未提供的账户操作 |
| 已注册插件来源 | 列出来源及提供者、已有搜索入口、高级身份/版本信息 | 私有客户端显示不支持该开关 | 不虚构插件启用或登录接口 |

只有 Registered / Ready 且确有相应能力的来源才能启动搜索、登录。管理入口不依赖这些动作可用。网络模式的持久化、DNS 和 socket 选择由 #214 负责；设置页不实现第二套网络逻辑。不支持绕过的来源不能打开开关，但可以关闭此前保存的开启偏好。

`variableComment` 只作作者说明。规则源无论是否提供说明，都可在“高级选项 → 编辑源变量”中手动编辑；主页面不铺空变量表单。未打开变量编辑器时，保存授权传入 `null`，保留原变量。变量与授权草稿使用 `rememberSaveable`，切换启用、网络偏好或忙碌状态不会清空草稿。

## 账户卡片

卡片只保留图标、主题底色、状态、可选账户名和操作，不为正常状态重复解释。颜色不是唯一提示；状态变化支持无障碍播报，操作使用可换行布局。

| 已保存状态 | 标题与含义 | 操作 |
| --- | --- | --- |
| `authenticated` | 登录已提交；脚本正常结束，不代表通用服务端认证 | 退出登录、次要的重新登录 |
| `session` | 会话已保存；网站可能仍要求登录 | 退出登录、次要的重新登录 |
| `required` | 需要重新登录 | 重新登录 |
| 缺省 | 未登录 | 登录 |
| 读取失败 | 无法读取账户状态；不宣称已经退出 | 重试读取，无需关闭页面 |

加载期间及操作期间按钮不可重复提交。禁用、等待授权或加载失败时仍显示已保存状态，并说明账户操作暂不可用。登录、表单动作、失败、取消及退出后重新读取当前账号存储，避免卡片残留先前的成功状态。网络失败是否保留会话，继续服从现有登录服务的判断。

脚本 `login()` 正常返回仍写入历史值 `authenticated`；网页流程完成写入 `session`。#217 将前者明确呈现为“登录已提交”，并接入已有网站验证动作，不把 HTTP 200 或存在 Cookie 等同于认证成功。完整的状态、动作和责任边界见 [SOURCE_LOGIN_STATE.md](SOURCE_LOGIN_STATE.md)。

### 可选账户名

账户卡片可显示“账户：reader”。名称来自当前账号已保存的 `LOGIN_INFO`，并满足：

- 表单中恰有一个 `text` 字段，其字段名（忽略首尾空白和大小写）属于 `user`、`username`、`account`、`email`、`账号`、`帐号`、`账户`、`用户名`、`邮箱`。
- 当前状态为 `authenticated` 或 `session`。
- 对应已保存值是字符串，去除首尾空白后长度为 1–128，且没有控制字符。

密码、令牌、其他控件、多个候选字段或格式不合法的数据都不给出账户名。完整凭据 map 不进入设置页状态；不解析 Cookie、猜测网站昵称或抓取页面资料。退出后名称随账号状态清除，不额外保存一份可能过期的昵称。

静态表单可以在再次打开设置和应用重启后恢复名称。动态表单仅在用户主动打开并提交后的当前页面，根据实际表单字段显示名称；重新打开设置时不会为获取名称执行脚本。纯网页登录没有统一用户名字段时只显示会话状态。

## 声明与存储边界

`RuleSettingsPresentation` 只处理固定分区需要的声明数据，复用现有 `LoginForm.parse`。没有登录字段、仅有 `loginCheckJs` 或空数组时，不提供空登录入口。非法声明显示具体字段位置，保留基础和网络修复入口。动态表单仅在扩展 profile 中声明为可用，页面打开时不执行。静态宽松数据的解析兼容由独立的 [#221](https://github.com/Renakoni/hnovel/pull/221) 交付。

`ImportedRuleSources.storedSettings/saveVariable` 在安装来源锁和当前账号代际保护下访问已有存储。已有同账号会话时直接复用；否则短暂创建仅访问存储的 broker，使用相同身份、profile、目录和 cipher，且没有站点授权、浏览器或解释器。这不会启用来源、注册运行时或轮换账号。

参考源码为本地 `legado-with-MD3` 的 `BaseSource.getLoginInfoMap`、`SourceLoginViewModel.buildForm/confirm`。参考项目以作者字段名保存加密的登录 map，未定义跨书源昵称字段；其某些读取路径会求值动态表单。本项目保留表单与账号存储的兼容边界，基础设置不照搬读取时执行脚本的行为。
