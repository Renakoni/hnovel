# 下载与阅读缓存

主修 [#68](https://github.com/Renakoni/hnovel/issues/68)。下载沿用现有书源接口和解析器：读取目录，逐章请求正文，解析出插画地址，再保存图片。它类似按目录抓取内容，但不是另建一个通用爬虫，也不会绕开来源身份、登录、请求调度或网络策略。

## 身份与存储

旧的“换源清数据库”背景是不同网站可能都使用书籍 `123`、章节 `1`。当前宿主已使用来源限定身份：书籍键包含来源与远端书籍 ID；章节键还包含所属书籍。切换浏览来源不再清空书库。本项继续使用这些身份，不依赖书名、作者或当前选择的来源。

| 数据 | 存储与清理边界 |
| --- | --- |
| 普通阅读正文 | Room `chapter_content`，可由“清理阅读缓存”删除 |
| 下载正文 | 同一正文表，加 `downloaded_chapter` 所有权记录；清理阅读缓存保留 |
| 普通封面、插画 | Coil 内存／磁盘缓存，可淘汰 |
| 下载封面、插画 | 应用私有 `files/book-downloads`，按来源限定书籍与 URI 区分，清理阅读缓存保留 |
| 书架、目录、阅读记录、账号 | 两个设置清理动作均保留 |

“清理下载”删除下载正文、图片和下载记录，并撤销旧任务的写入资格。正常阅读仍可能重新产生阅读缓存。卸载或 Android 的“清除应用数据”会删除应用私有下载；长期保存到用户选择的位置继续使用现有 EPUB 导出。

书籍管理器显式删除某本书或清理其正文时，同步取消该书下载并删除下载图片。清理孤立数据仍保留下载所有的章节，即使该章节已从远端目录移除。

普通阅读刷新可以显示新的在线内容，但不能覆盖一份已下载正文。显式下载更新在本章图片全部保存后，才原子替换正文和所有权；失败保留此前可用的副本。图片复制保留源文件字节，不把解码后的缩略图当作下载文件。无法取得或确认原始图片落盘时，任务明确失败。

## 更新与状态

- 每次检查更新都向来源获取目录与元数据，跳过宿主短期响应缓存。阅读流程保留原有缓存行为。
- 增量复用比较来源修订、章节 ID／标题、相邻章节 ID。卷和章节顺序参与目录版本；新增、改名、调整顺序及来源修订会触发相应更新。
- 未变化且完整的章节跳过；正文已存但缺图时只补图；更新失败后重试尚未完成或变化的部分。
- 远端失败不能被阅读流程的本地回退伪装成更新成功；空目录不能宣称完整下载。
- 状态区分未下载、部分下载、已下载、下载中、失败和有更新。已下载可以检查更新；部分下载可以继续；失败可以重试。应用重启后根据实际正文、图片及任务记录恢复状态。
- 网站在同 ID、同标题下静默修改正文，而没有可用的正文版本信息时，本项无法自动识别该变化。

下载写入由 `BookDownloadStore` 串行校验所有权及任务代次；网络请求不持有存储锁。WorkManager 负责调度、取消和在途状态。普通阅读、下载任务和设置界面共享存储事实，不共享一个“看起来下载完成”的布尔值。

## 升级与备份

Room 17 → 18 只增加下载记录表，保留原书库。可识别的旧 `CACHE` 完成记录表示下载意图，升级时采用仍存在的正文，并复制仍可取得的图片；缺失文件保持部分下载。每本书迁移失败可重试，不能先标记完成再漏掉后续图片。

现有 CBOR 备份增加可选下载所有权列表，旧备份仍可读取。备份继续保存数据库内容，不新增图片归档；恢复后缺图的书籍保持部分下载，可继续补图。导出排除活动任务 ID／本机清理代次，导入不采用备份中的任务代次；覆盖恢复撤销旧下载任务，不能复活清理前的写入资格。

## 参考项目

对照 `legado-with-MD3` 的提交 `fb01a76ebbbca41423e2c4c00080cc0861239fbd`：

- [BookHelp](https://github.com/HapeLee/legado-with-MD3/blob/fb01a76ebbbca41423e2c4c00080cc0861239fbd/app/src/main/java/io/legado/app/help/book/BookHelp.kt) 使用每本书的正文／图片文件，并检查正文和图片是否存在。
- [CacheBookModel](https://github.com/HapeLee/legado-with-MD3/blob/fb01a76ebbbca41423e2c4c00080cc0861239fbd/app/src/main/java/io/legado/app/model/CacheBookModel.kt) 跳过完整章节，对已有正文补齐缺图。

本项目采用这些成熟的增量思路，继续使用已有 Room 正文存储。参考项目的整库缓存清理仍可能移除下载文件；本项目按用户要求明确分离“清理阅读缓存”和“清理下载”。

## 回归范围

`BookDownloadTest` 使用真实 Room、来源响应缓存、Coil、下载 Worker，覆盖正文与图片离线保留、重建、增量和失败重试、空目录、缺图、来源修订、迟到任务、Room 升级及备份。已有多来源集成测试继续覆盖相同远端 ID、导入书源图片处理、导出和离线阅读。不以模拟器的宿主网络状态作为物理直连证明。
