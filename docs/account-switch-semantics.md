# 账号切换与本地内容

2026-09-10 用户确认的产品语义，适用于来源登录、浏览器、图片、缓存和来源管理。

本应用按同一个人使用设计。账号是访问来源网站时的认证状态，不是本地书库或阅读数据的所有者。

- 换账号、退出登录、取消登录不清理任何阅读缓存。书架、书籍、目录、阅读记录、进度、正文、封面、插画、规则保存的数据和下载资源均保留。
- 图片按来源、书籍、资源地址及处理修订区分，不按账号、Cookie 或 Authorization 区分。不同来源的同名同作者书籍仍然是独立书籍。
- 只替换明确的登录状态：Cookie、登录表单凭据、登录 headers、登录状态。撤销旧会话的请求，避免迟到响应恢复旧 Cookie；撤销不触发图片或内容删除。
- `source.put/get` 是来源的通用持久数据，不能因为可能包含某种秘密就一律归入注销清理范围。专用 LoginInfo/LoginHeader API 才属于登录凭据。
- 浏览器 localStorage 的通用内容按来源保留；Cookie 和明确的登录凭据仍由登录会话管理。不能把整个浏览器持久数据当作账号私有内容删除。
- 设置提供独立的「清理阅读缓存」操作，明确删除已下载正文和图片，保留书架、阅读记录、目录和登录状态。正常缓存过期、容量淘汰继续按各缓存自身策略执行。

实现以高内聚、低耦合、单一职责及 KISS 为准；不建立账号图片隔离策略框架。旧 issue/PR 中关于注销删除图片、账号内容缓存或任意来源数据的描述，由本文明确语义取代。
