0, 9, 17, 18 and 19 in
[XIU2/Yuedu@426b24f59aa763ee0f2d9cc094612d2ef42c8293/shuyuan](https://github.com/XIU2/Yuedu/blob/426b24f59aa763ee0f2d9cc094612d2ef42c8293/shuyuan).

`00644eda44f0fcabcfc015a024480376638d5e7a381a2010aeedfca5aa797845`.

Only catalogue metadata is included. Row order, titles, targets and style values
are unchanged; JSON whitespace is compacted for review. No headers, cookies,
login data, fetched books or chapter text are copied. Tests never fetch these
targets. Source 9 is disabled in the original definition; parser coverage does
not imply that the application activates it automatically.
