# 书源目录

`catalog.json` 保存展示名称、六类分类、展示域名及对应定义在批次中的位置；`key` 必须与批次中完整的 `bookSourceUrl` 一致。分类只按该身份匹配，不从名称、原分组或域名推断。

六个批次供用户在“添加书源”中明确勾选后导入，继续经过现有预览、权限和更新流程。目录收录及静态导入通过不代表站点当前在线可用。

维护批次时保留规则、作者说明及来源身份。不要提交个人 Cookie、账号标识或 token；本目录已移除 UAA 的固定 token / 统计 Cookie 和豆腐阅读的固定账号 Cookie。登录会话由现有书源会话管理处理。

变更批次后同步目录索引，并运行 `SourceCatalogTest`。
