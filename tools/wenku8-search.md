# Wenku8 搜索索引

搜索同时查询 Wenku8 原站、本地目录和 Bangumi 的公开关键词／标签接口。Bangumi 名称、别名与小说系列关系用于找到 Wenku8 ID；未匹配的可信系列名最多补搜两次原站。按 Wenku8 ID 去重，保留续作，分批展示，每次只加载一页。其他书源沿用原有搜索协议。

“加载更多书籍”表示至少一路还有下一页候选。点击后仅继续未结束的通道，本地目录每页 20 本，Bangumi 关键词和标签各取 10 项，原站使用自己的分页；去重后追加结果。后续候选可能重复、无关或无法对应 Wenku8，因此按钮不保证下一页一定新增书籍。

本地查询归一化简繁体、全半角、大小写和标点，保留原始显示名称。数字仍参与书名搜索，并补充同 ID 候选；`#1973` 或 Wenku8 书籍／目录链接明确表示 ID。目录预览不写入书籍正文或目录表，展示时仍通过书源读取完整元数据。

Bangumi 和目录更新属于可选补充：失败或超时不产生整次搜索错误。Wenku8 请求失败会保留已有结果并显示来源错误。关键词和标签请求并行，Bangumi（含备用线路）最多同时发出四个 HTTP 请求、每页最多六次关系查询、关系深度两层；整个补充阶段最多 20 秒。所有原站关键词搜索共享至少五秒间隔。

## 数据来源与更新

- 来源：[mojimoon/wenku8](https://github.com/mojimoon/wenku8)，MIT 许可，副本位于 `app/src/main/assets/wenku8-search/LICENSE`。
- 初始版本：`e421ed7a064e03da04219d454d41d063288a4eed`，2026-10-02。
- 输入：`out/wenku_catalog.json` 与 `out/txt_alias.csv`。后者只有九条人工修正，并非完整的缩写词典。
- 4,335 本书，仅保留 ID、名称、作者和已有别名，不含正文、封面或简介。
- UTF-8 TSV 为 223,024 字节；确定性 gzip 为 116,911 字节，相比原始 JSON 的 1,842,244 字节减少约 94%。加载后只缓存搜索键，不复制完整上游 JSON。

从已下载的上游仓库重新生成：

```sh
python tools/update_wenku8_catalog.py \
  --catalog /path/to/wenku8/out/wenku_catalog.json \
  --aliases /path/to/wenku8/out/txt_alias.csv \
  --output app/src/main/assets/wenku8-search/catalog.bin
```

资源使用 `.bin` 后缀保留 gzip 内容，避免 Android 打包器自动解压、去除 `.gz` 后缀。缓存文件不经过打包器。

TSV 第一行是 `wenku8-search-v1`，后续字段以制表符分隔：`ID / 名称 / 作者 / 零到多个别名`。更新时核对上游版本、数量与许可，并更新本说明。

首次搜索使用内置表，后台最多每天从 `https://wenku.mojimoon.top/` 的内嵌 JSON 合并更新；该页面是完整表的子集，缺失条目不删除。原站搜索见到的新书也补入缓存，原站仍负责最新收录。缓存采用原子写入，损坏时回退内置表。

可删除缓存位于 `cacheDir/wenku8-search`，计入设置的阅读缓存并随之清理；内置基础表属于应用资源。清理会阻止已在途请求重新写回旧缓存。

## 网络与验证边界

优先使用现有 `api.bgm.tv` 公开 API，无需登录。官方请求失败时立即尝试 `api.bangumi.vip`；750 毫秒仍未完成时并发启动这条备用线路，采用先成功的响应并取消另一条。每个请求最多八秒，关系展开阶段总共最多 16 秒。`bangumi.vip` 网页有浏览器验证，实际使用的是已验证兼容的 API 子域名。

镜像只用于 Wenku8 的公开关键词、标签和条目关系查询，使用独立无 Cookie 的客户端，不接收账号令牌，也不参与 Bangumi 同步。`bgm.tv`、`bangumi.tv` 是网页域名，不能直接当作可互换 API。两条线路均不可达时，尚未存在于本地表中的缩写可能仍没有结果；本功能不修改 DNS、代理或 TLS 配置。

回归测试覆盖关键词与标签互补、单卷到系列、续篇去重、可选服务故障、原站故障保留结果、简繁体、数字书名、取消、分页、缓存及清理。`Wenku8SearchDeviceTest` 的联网检查必须显式传入 `liveWenku8=true`；需要直连 Bangumi 的缩写端到端断言另需 `liveBangumiRecall=true`。普通 CI 不依赖公网服务。

`app/src/test/resources/wenku8-search/bangumi-recall.json` 保存 2026-10-02 调研取得的公开 API 响应，用于春物、俺妹、实教、魔禁的回放验证。保留每路前十项及原始排序、所有已记录的关系条目，仅去除召回不使用的字段；未记录的关系请求模拟为不可用。测试分别让关键词、标签先返回，以验证漫画等干扰项及并发顺序不会挤掉目标小说。该文件只属于测试资源，不随应用分发。
